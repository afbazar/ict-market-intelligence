# ICT Market Intelligence

داشبورد هوشمندی بازار فناوری اطلاعات و ارتباطات با تمرکز اولیه بر بازار ایران و کاربرد آن برای شرکت‌های مرکز رشد ICT دانشگاه رازی.

## وضعیت فعلی

- داشبورد فارسی و راست‌چین با داده‌های JSON.
- داده‌های اولیه تجارت الکترونیکی، اتصال و زیرساخت ارتباطی ایران با منابع ITU، World Bank و مرکز توسعه تجارت الکترونیکی.
- گزارش پایه بازار ICT ایران در `reports/iran-ict-market-baseline-1405.md`.
- شاخص‌های فاقد داده عمومی معتبر عمداً خالی می‌مانند و در برنامه پژوهش ثبت شده‌اند.
- گزارش پایه تحلیلی در `reports/iran-ecommerce-market-1403.md`.
- کتابخانه گزارش‌ها در `data/reports.json`.
- شاخص‌ها و سری‌های زمانی در `data/indicators.json`.
- گردش‌کار GitHub Actions برای ایجاد وظیفه مرور هفتگی و ماهانه در Issues.

## اجرای محلی

به دلیل استفاده از `fetch()` برای خواندن JSON، پروژه را از طریق یک وب‌سرور محلی اجرا کنید؛ برای مثال افزونه Live Server در VS Code. باز کردن مستقیم `index.html` با آدرس `file://` ممکن است بارگذاری JSON را مسدود کند.

## به‌روزرسانی داده‌ها

### ثبت شاخص

هر رکورد در `data/indicators.json` باید تا حد امکان این فیلدها را داشته باشد:

- `id`: شناسه یکتا و ثابت
- `name` و `definition`: نام و تعریف عملیاتی
- `value` و `unit`: مقدار و واحد
- `year` و `publication_year`: سال داده و سال انتشار
- `geography`: محدوده جغرافیایی
- `data_type`: یکی از Fact، Calculation یا Insight
- `source_name`, `report_title`, `source_url`, `page`: شناسنامه منبع
- `methodology` و `notes`: روش و محدودیت‌ها
- `series`: آرایه اختیاری نقاط زمانی با `year` و `value`

اگر مقدار معتبر در دسترس نیست، `value` را null نگه دارید. داده‌های تاریخی را حذف نکنید؛ نقطه جدید به سری زمانی اضافه کنید.

### ثبت گزارش

گزارش‌ها را در `data/reports.json` اضافه کنید. لینک باید به سند اصلی ناشر برسد. نوع منبع یکی از `official`, `industry`, `research` باشد.

## چرخه پایش

- **هفتگی:** گردش‌کار `.github/workflows/market-intelligence-review.yml` یک Issue برای مرور خبرها، اطلاعیه‌ها، سیگنال‌ها و فرصت‌ها ایجاد می‌کند.
- **ماهانه:** همان گردش‌کار یک Issue برای کنترل گزارش‌های تازه، به‌روزرسانی شاخص‌ها، تحلیل تغییرات و انتشار جمع‌بندی ایجاد می‌کند.
- اجرای دستی از تب Actions نیز قابل انجام است؛ وظایف هفتگی و ماهانه با زمان‌بندی خودکار ایجاد می‌شوند.

این گردش‌کار یادآور و مدیریت فرایند است، نه ربات استخراج خودکار داده یا تولید تحلیل. ورود هر داده باید با کنترل منبع انجام شود. برای اتوماسیون واقعی استخراج، باید برای هر منبع API/RSS یا روش مجاز و پایدار جداگانه تعریف و تست شود.

## اصول روش‌شناسی

1. ارزش معاملات تجارت الکترونیکی با ارزش افزوده صنعت ICT یا اندازه کل اقتصاد دیجیتال یکی نیست.
2. رشد اسمی با رشد واقعی پس از تعدیل تورم متفاوت است.
3. ضریب نفوذ اشتراک تلفن همراه یا اینترنت، لزوماً درصد افراد یکتای متصل نیست.
4. تعداد اینمادها، تعداد کل شرکت‌های ICT یا بنگاه‌های فعال اقتصاد نیست.
5. Fact، Calculation و Insight باید جداگانه برچسب‌گذاری شوند.
6. هر عدد باید واحد، دوره، جغرافیا و منبع قابل بررسی داشته باشد.
